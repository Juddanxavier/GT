## Color

### Semantic Roles (Applies to Both Tenants)

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `var(--background)` / `#FFFFFF` | Page background, hero base, section backgrounds |
| Secondary (30%) | `var(--surface-secondary)` / gray-50 | Feature cards, tracking search section background, footer background |
| Accent (10%) | **Emerald-600** (Gajan) / **Violet-600** (Lanka Mahal) | CTAs, active nav links, brand logo badge, focus rings, hero gradient accent |
| Destructive | `var(--danger)` / red-500 | Error messages, destructive actions (none in this phase — reserved) |

### Tenant-Specific Accent Mapping

| Element | Gajan Traders (`emerald`) | Lanka Mahal (`violet`) |
|---------|--------------------------|------------------------|
| CTA Button background | `bg-emerald-600 hover:bg-emerald-700` | `bg-violet-600 hover:bg-violet-700` |
| Active nav link text | `text-emerald-700` | `text-violet-700` |
| Nav hover link text | `hover:text-emerald-700` | `hover:text-violet-700` |
| Brand logo badge bg | `bg-emerald-600` | `bg-violet-600` |
| Hero gradient accent | `from-emerald-500 to-emerald-700` | `from-violet-500 to-violet-700` |
| Feature icon bg | `bg-emerald-100 text-emerald-700` | `bg-violet-100 text-violet-700` |
| Focus ring | `focus:ring-emerald-500` | `focus:ring-violet-500` |
| Link/button accent text | `text-emerald-600` | `text-violet-600` |

Accent reserved for: **CTAs (primary buttons, register link), active navigation indicators, brand logo badge, feature card icons, focus rings, hero gradient overlays.** Never used for body text, borders, or backgrounds outside these elements.

**Source:** CONTEXT.md D-05 (tenant brand colors), portal-nav.tsx (existing emerald/violet class patterns), page.tsx (existing usage), globals.css (CSS variable tokens).

## Interaction States

### Navbar

| State | Behavior |
|-------|----------|
| **Default** | Sticky top header, `bg-surface/80 backdrop-blur-sm`, border-bottom. Logo + brand name left, nav links right. |
| **Active link** | Nav link matching current pathname has accent color (`text-emerald-700` / `text-violet-700`) |
| **Hover (link)** | `hover:text-foreground` for muted links, `hover:text-emerald-700` / `hover:text-violet-700` for brand accent |
| **Hover (CTA)** | Register/Sign in buttons: `hover:bg-emerald-700` / `hover:bg-violet-700` (1-step darker) |
| **Mobile** | Icon-only nav labels (`hidden sm:inline` — matches current PortalNav). No hamburger menu in this phase. |
| **Logged-in** | Shows: My Shipments, Quotations, Invoices, Notifications (with unread badge), Profile, Sign out |
| **Logged-out** | Shows: Sign in (link), Register (CTA button) |
| **Loading (session)** | Renders logged-out view as safe default while session resolves |
| **Empty (unread)** | No badge rendered when `unreadCount === 0` |

### HeroSection

| State | Behavior |
|-------|----------|
| **Default** | Full-width section with gradient background + subtle pattern overlay. Centered content stack: icon/illustration, headline (36px), subtitle (14px muted), CTA buttons. |
| **Hover (CTA button)** | Background darkens 1 step (`bg-emerald-600 → bg-emerald-700`), slight scale/transition |
| **Loading** | Not applicable — HeroSection is server-renderable, no async data dependency |
| **Empty** | Not applicable — all content is static props from tenant config |

### Tracking Search Section

| State | Behavior |
|-------|----------|
| **Default** | Section with distinct background. Title "Track Your Shipment" (18px semibold), subtitle (14px muted) optional. TextField + "Track" button with ArrowRight icon. |
| **Focus** | Input field: `focus:ring-accent` (emerald-500/violet-500) via HeroUI TextField |
| **Disabled** | Track button disabled when input empty `isDisabled={!trackingNo.trim()}` |
| **Loading** | Button shows `isPending` spinner via HeroUI, input remains editable |
| **Error** | Red text below form: "Shipment not found. Please check your tracking number and try again." — dismissible by editing input |
| **Success** | Results shown below form (existing tracking result card pattern — full detail reuses existing tracking view) |
| **Empty input** | Placeholder text: "Enter tracking number" |

### Footer

| State | Behavior |
|-------|----------|
| **Default** | Dark/colored background (`gray-900` or `surface-tertiary`). 4-column grid: brand/about, quick links, contact info, social icons. Bottom bar with copyright. |
| **Hover (link)** | `hover:text-foreground` for footer links |
| **Hover (social)** | Social icon opacity change, color shift to accent |
| **Newsletter (if implemented)** | Not in scope for this phase per D-11 ("optional"). Defer to agent discretion. |

### Logged-in Redirect

| State | Behavior |
|-------|----------|
| **Session pending** | Brief loading skeleton or null render while `authClient.useSession()` resolves |
| **Session exists** | `useEffect` fires `router.push('/my-shipments')` — landing page content never renders |
| **No session** | Full landing page renders (Hero → Tracking Search → Features → Footer) |

## Component Theming API

### Shared Type Definition (`packages/ui/src/tenant-types.ts`)

```typescript
export type TenantTheme = 'emerald' | 'violet';

export interface NavLink {
  label: string;
  href: string;
  icon?: string;         // lucide icon name — consumer passes resolved ReactNode
  match?: string[];      // path prefixes for active state detection
}

export interface ContactInfo {
  address?: string;
  phone?: string;
  email?: string;
}

export interface SocialLink {
  platform: 'facebook' | 'twitter' | 'instagram' | 'linkedin';
  url: string;
}

export interface TenantConfig {
  name: string;
  shortName: string;
  theme: TenantTheme;
  logo?: string;
  title?: string;
}

export interface FooterConfig {
  contact?: ContactInfo;
  socialLinks?: SocialLink[];
  navLinks?: { label: string; href: string }[];
}
```

**Source:** CONTEXT.md D-17 (tenant prop shape), RESEARCH.md §Tenant Prop API Design, tenant-config.ts (existing shape).

## Data Flow

```
Customer Portal (apps/customer)
─────────────────────────────────
proxy.ts → sets x-tenant-slug header
  ↓
app/layout.tsx → reads header, picks GajanLayout/LankaLayout (simplified wrappers)
  ↓
(portal)/layout.tsx → renders Navbar from @repo/ui
  ├─ useTenantConfig() → TenantConfig          (from DOM data-tenant-slug)
  ├─ authClient.useSession() → session          (or null)
  ├─ useUnreadCount() → unread count            (or 0)
  └─ passes all as props to <Navbar>

(portal)/page.tsx → renders landing page
  ├─ useTenantConfig() → TenantConfig
  ├─ authClient.useSession() → session          (null → show landing, exists → redirect)
  ├─ passes tenant to <HeroSection>
  ├─ passes tenant to <Footer>
  └─ inline TrackingSearchSection
```

**Key constraint:** `@repo/ui` components never import `better-auth`, `@tanstack/react-query`, or `@/lib/*`. All data is passed via props from the consumer.

**Source:** CONTEXT.md D-02, D-06, D-12, D-15, D-16, D-18. RESEARCH.md §Data Flow.
