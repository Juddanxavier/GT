## Objective

Make the Reports page actionable: download report data as CSV and visualize the shipments status/branch distribution.

## Tasks

### 8.2.1 CSV export on Reports

- `apps/admin/app/(dashboard)/reports/page.tsx`:
  - Add **Export CSV** button (like shipments page): takes current `reportType` (shipments|quotations), `start`, `end`, `branchFilter`.
  - Shipments → fetch `/api/reports/shipments/data` (respect `limit` up to 200, paginate through `offset` for full export); Quotations → `/api/reports/quotations/data`.
  - Map the returned rows to header-labeled CSV; client-side Blob download `report-{type}-{start}-{end}.csv`.
  - CSV cell escaping identical to shipments page helper.

### 8.2.2 Charts on shipments report

- Use existing `/api/reports/shipments` aggregates already loaded by the page:
  - **Status distribution** — simple horizontal bars (custom markup) from `statusDistribution`, colored via `STATUS_COLORS`/`STATUS_META` from `@lib/status-config`.
  - **Branch comparison** — bars from `branchComparison` (mono accent).
- Reuse `CardMiniChart` bar style is only for trends; implement minimal bar rows (label + track + value) — no chart library.
- Dark-mode safe: `bg-muted/…`/`text-*` tokens only.
