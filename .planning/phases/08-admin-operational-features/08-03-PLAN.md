## Objective

Quickly find any shipment, customer, or invoice from anywhere in the admin app with a keyboard-triggered search modal.

## Tasks

### 8.3.1 Search hook

- `apps/admin/lib/queries.ts`: `useSearch(q)` — React Query, queryKey `['search', q]`, queryFn `api.get('/api/search?q=' + encodeURIComponent(q))` returning `{ shipments, customers, invoices }` (matches `/api/search` shape). Only fires when `q.trim().length >= 2`.

### 8.3.2 Search modal component

- `apps/admin/components/global-search.tsx`:
  - Modal (`Modal.Backdrop`/`Container`/`Dialog` per HeroUI v3 pattern) with autofocus `Input`, debounced query (300ms), loading spinner, empty state.
  - Results grouped: Shipments (trackingNo + status badge → `/shipments/{id}`), Customers (name + email → `/customers/{id}`), Invoices (invoiceNo + amount → `/invoices/{id}`).
  - Keyboard: `Esc` closes; `Enter` opens first result; arrow navigation optional (skip if fiddly).
  - Shortcut: global `keydown` listener for `Cmd/Ctrl+K` (preventDefault, open modal). Mount in layout.

### 8.3.3 Wire into layout

- `apps/admin/app/(dashboard)/layout.tsx`: render `<GlobalSearch />` once; add a small search button in the header/sidebar that opens it (discoverability).

### 8.3.4 Scope note

- Search is tenant/branch-scoped server-side (current tenant filter). Superadmin searches within the active tenant filter. Document this in the modal empty state if desired — no code change.
