# 08-03: Dashboard UI with Tremor Charts

## Goal

Replace the 4-card count dashboard with a full KPI dashboard featuring 6 metric cards, a status distribution donut chart, a shipments-per-day bar chart, and an alert list — all powered by `GET /api/dashboard/stats` and receiving real-time pushes via Socket.IO.

## Files Changed

| File | Action |
|------|--------|
| `apps/admin/package.json` | Edit — add `@tremor/react` dependency |
| `apps/admin/app/(dashboard)/page.tsx` | Rewrite — full dashboard layout |

No new files — all UI is inline in `page.tsx`.

## Role-Conditional Rendering

Single `page.tsx` switches layout based on `data.role` from the API:

```ts
if (data.role === 'superadmin') return <SuperadminDashboard data={data} />;
return <OperationalDashboard data={data} role={data.role} />;
```

## Per-Tenant Table (superadmin only)

HeroUI `Table` with 6 columns — one row per tenant:

| Column | Data | Type |
|--------|------|------|
| Tenant | `perTenant[n].tenantName` | Text + colored dot |
| Shipments | `perTenant[n].shipments.total` | Number |
| In Transit | `perTenant[n].shipments.inTransit` | Number + Chip |
| Delivered | `perTenant[n].shipments.delivered` | Number |
| Revenue | `perTenant[n].invoices.revenueTotal` | Currency (₹) |
| Branches | `perTenant[n].branches.total` | Number |

- Each row links to that tenant's filtered view (future — just `/tenants/{id}` for now)
- No pagination needed (max ~5-10 tenants)
- Responsive: on mobile, collapses to card layout (tenant name as header, stats as rows)

## Tremor Charts

Install: `pnpm add @tremor/react` in `apps/admin`.

Import only chart components to keep bundle small:
```ts
import { DonutChart, BarChart } from '@tremor/react';
```

**DonutChart — Status Distribution**:
- Data: `Object.entries(shipments.byStatus).map(([status, count]) => ({ name: statusLabel(status), value: count }))`
- Helper `statusLabel()` maps internal status keys to display labels (capitalize, replace underscores)
- Value formatter: `(n) => n.toString()`
- Colors: standard cat 12 palette
- Show legend below chart (Tremor default)
- Height: `h-64`
- No tooltip customizations needed

**BarChart — Shipments Per Day** (tenant-admin/staff):
- Data: `shipments.perDay.map(d => ({ date: formatDate(d.date), shipments: d.count }))`
- Index: `"date"`
- Categories: `["shipments"]`
- Colors: `["blue"]`
- Value formatter: `(n) => n.toString()`
- Height: `h-64`
- Show X-axis labels (date), Y-axis grid lines

**Stacked BarChart — Shipments Per Day** (superadmin):
- Same data shape but `perDay` includes per-tenant breakdown
- Index: `"date"`
- Categories: tenant names (e.g., `["Gajan Traders India", "Gajan Traders Sri Lanka"]`)
- Colors: distinct per tenant (e.g., `["blue", "emerald"]`)
- Height: `h-72`
- Legend below chart showing tenant colors

## Alerts Section

Card with title "Alerts — Shipments Needing Attention".

Each alert is a row with:
- Icon based on type (stale= `Clock`, overdue= `CalendarClock`, exception= `AlertTriangle`)
- Tracking number (link to `/shipments/{id}`)
- Description text
- Color: stale=amber, overdue=orange, exception=red

Empty state: "No alerts — all shipments are on track" with a `CheckCircle2` icon in green.

Limit to 10 alerts. If more, show "View all shipments →" link to `/shipments` with status filter.

## Branch Filter (tenant-admin only)

HeroUI `Select` dropdown next to the page title, populated from `GET /api/dashboard/branches`:

```
Dashboard  [Branch: All Branches ▼]  ● Live
```

- First option: "All Branches" (value = `""`)
- Remaining options: each branch from the API response
- On change: re-fetch stats with `?branchId=`
- Socket.IO `dashboard:update` events re-fetch with current branchId filter
- **Staff users**: dropdown hidden entirely — they see a chip instead: "Branch: Chennai HQ"

## Live Indicator

Small green dot with "Live" text next to the welcome message when Socket.IO is connected. Gray "Disconnected" when not.

## Loading State

Full-page skeleton while stats load:
- 6 KPI cards rendered as `Card` with pulsing `div` placeholders
- 2 chart areas with larger pulsing rectangles
- Alerts section with 3 skeleton rows

## Error State

If API fails:
- Cards show `—` instead of number
- Toast-style error banner at top: "Failed to load dashboard data. [Retry]"
- Charts hidden, alerts section shows "Unable to load alerts"

## Styling Notes

- All layout uses Tailwind grid + flex, no custom CSS
- Tremor charts can be wrapped in a `Card` with `bg-surface` to match HeroUI look
- Tremor's default theme respects Tailwind classes — no tremor theme customization needed unless colors clash
- Responsive: KPI cards go from 6-col → 3-col → 1-col on mobile
- Chart containers go from side-by-side (lg) → stacked (sm)
