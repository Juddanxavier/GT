<objective>
Harden the webhook and notification pipeline: convert the 17TRACK webhook handler from inline processing to a BullMQ queue-based architecture with retry/DLQ, add an in-memory LRU fallback cooldown when Redis is unavailable, and confirm existing rate limits are adequate.

**Purpose:** Webhook events from 17TRACK are currently processed inline in the handler — if processing fails (e.g., DB timeout), the webhook is lost. Moving to a queue guarantees delivery with 3 retry attempts and a dead-letter queue for unrecoverable failures. The in-memory LRU prevents duplicate notification spam during Redis outages without adding infrastructure dependencies.

**Output:** Queue-backed webhook handler, webhook worker, LRU fallback cooldown in notification service.
</objective>

        .where(eq(shipments.trackingNo, result.trackingNo))

      const inserted = await insertEvents(shipment.id, shipment.tenantId, result.events);

      // Notify if new events were inserted
      if (inserted > 0) {

      }

      return { processed: true, eventsInserted: inserted };

    // In apps/api/src/notifications/service.ts or a small util file
    class SimpleLRU<K, V> {
      private max: number;
      private map = new Map<K, V>();
      constructor(max: number) { this.max = max; }

      get(key: K): V | undefined {
        const val = this.map.get(key);
        if (val !== undefined) {
          // Move to end (most recently used)
          this.map.delete(key);
          this.map.set(key, val);
        }
        return val;
      }

      set(key: K, value: V): void {
        if (this.map.has(key)) this.map.delete(key);
        else if (this.map.size >= this.max) {
          // Delete least recently used (first inserted)
          const firstKey = this.map.keys().next().value as K;
          this.map.delete(firstKey);
        }
        this.map.set(key, value);
      }

      has(key: K): boolean { return this.map.get(key) !== undefined; }
    }

    // Singleton instance — shared across the process lifetime
    export const cooldownCache = new SimpleLRU<string, boolean>(10000);
