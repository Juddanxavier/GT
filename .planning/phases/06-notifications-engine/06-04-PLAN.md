# 06-04: WhatsApp Notifications via MSG91

## Objective

Add WhatsApp notification channel via MSG91. Integrate into the existing notification worker fan-out so WhatsApp is sent alongside email for each major tracking event.

## Context

- "MSG91 (WhatsApp/SMS) — already proven in GT Express" (AGENTS.md)
- Idempotency system from 06-03 supports multi-channel (`email` / `whatsapp`)
- Notification worker already fans out to email — add WhatsApp as second channel
- MSG91 requires pre-approved WhatsApp templates — need template names/IDs per event type

## Tasks

### Task 4.1: Create MSG91 config and env vars

**Action:**
1. Add to `.env` and `.env.example`:
```env
# MSG91 / WhatsApp
MSG91_AUTH_KEY="your-msg91-auth-key"
MSG91_WHATSAPP_SENDER="your-whatsapp-sender-number"
MSG91_TEMPLATE_ID_PICKEDUP="template_id_1"
MSG91_TEMPLATE_ID_INTRANSIT="template_id_2"
MSG91_TEMPLATE_ID_OUTFORDELIVERY="template_id_3"
MSG91_TEMPLATE_ID_DELIVERED="template_id_4"
MSG91_TEMPLATE_ID_EXCEPTION="template_id_5"
```

2. Create `apps/api/src/notifications/whatsapp/config.ts`:
```typescript
export const whatsappConfig = {
  authKey: process.env.MSG91_AUTH_KEY || '',
  sender: process.env.MSG91_WHATSAPP_SENDER || '',
  templates: {
    InfoReceived: process.env.MSG91_TEMPLATE_ID_PICKEDUP || '',
    InTransit: process.env.MSG91_TEMPLATE_ID_INTRANSIT || '',
    OutForDelivery: process.env.MSG91_TEMPLATE_ID_OUTFORDELIVERY || '',
    Delivered: process.env.MSG91_TEMPLATE_ID_DELIVERED || '',
    Exception: process.env.MSG91_TEMPLATE_ID_EXCEPTION || '',
  },
};

export function isWhatsAppConfigured(): boolean {
  return !!whatsappConfig.authKey && !!whatsappConfig.sender;
}
```

### Task 4.2: Create MSG91 WhatsApp provider

**Action:**
1. Create `apps/api/src/notifications/whatsapp/provider.ts`:

```typescript
import { whatsappConfig, isWhatsAppConfigured } from './config';

type SendWhatsAppParams = {
  to: string; // Phone number with country code
  templateId: string;
  variables: Record<string, string>;
};

export async function sendWhatsApp(params: SendWhatsAppParams): Promise<void> {
  if (!isWhatsAppConfigured()) {
    throw new Error('MSG91 not configured — MSG91_AUTH_KEY or MSG91_WHATSAPP_SENDER missing');
  }

  const response = await fetch('https://api.msg91.com/api/v5/whatsapp/whatsapp-outgoing-message', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'authkey': whatsappConfig.authKey,
    },
    body: JSON.stringify({
      integratedNumber: whatsappConfig.sender,
      contentType: 'template',
      to: params.to,
      templateId: params.templateId,
      variables: params.variables,
    }),
  });

  if (!response.ok) {
    const body = await response.text();
    throw new Error(`MSG91 WhatsApp send failed (${response.status}): ${body}`);
  }
}
```

### Task 4.3: Create WhatsApp template variable mapper

**Action:**
1. Create `apps/api/src/notifications/whatsapp/templates.ts`:

```typescript
import { whatsappConfig } from './config';
import type { ShipmentData } from '../../email/types';
import type { EventType } from '../../email/templates';

type TemplateVars = Record<string, string>;

export function getWhatsAppTemplateParams(
  eventType: EventType,
  shipment: ShipmentData,
): { templateId: string; variables: TemplateVars } | null {
  const templateId = whatsappConfig.templates[eventType];
  if (!templateId) return null;

  const variables: TemplateVars = {
    customer_name: shipment.customerName ?? 'Valued Customer',
    tracking_no: shipment.trackingNo,
    carrier: shipment.carrier ?? '',
    origin: shipment.origin ?? '',
    destination: shipment.destination ?? '',
    estimated_delivery: shipment.estimatedDelivery ?? '',
    status: shipment.status,
  };

  return { templateId, variables };
}
```

### Task 4.4: Add WhatsApp fan-out to notification worker

**Action:**
1. Update `notificationWorker` in `apps/api/src/workers/index.ts` — add WhatsApp after email:

```typescript
// Inside notificationWorker processor, after email enqueue:

// WhatsApp fan-out
if (customer.phone && isWhatsAppConfigured()) {
  const alreadySentWhatsApp = await checkAndSetIdempotency(eventId, shipmentId, 'whatsapp');
  if (!alreadySentWhatsApp) {
    const whatsappParams = getWhatsAppTemplateParams(eventType as EventType, shipmentData);
    if (whatsappParams) {
      // Enqueue to a WhatsApp queue or send directly
      // For now, send directly since MSG91 is a simple HTTP call
      try {
        await sendWhatsApp({
          to: customer.phone,
          ...whatsappParams,
        });
      } catch (err) {
        console.error(`[notifications] WhatsApp send failed for ${shipmentId}:`, err);
        throw err; // Let BullMQ handle retry
      }
    }
  }
}
```

*Note: If WhatsApp volume is high, create a dedicated `whatsappQueue` for rate limiting. For initial integration, direct HTTP in the notification worker is acceptable.*
